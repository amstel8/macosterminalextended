# Возможности

[English](../FEATURES.md) · **Русский** · [Главная](../../README.ru.md)

Extended Terminal расширяет стандартный Терминал на macOS 12 Monterey. Он работает как скрытая фоновая служба, а настройки доступны через нативную панель Системных настроек.

## Управление с клавиатуры

| Сочетание | Действие |
| --- | --- |
| Ctrl + ← / → | Начало / конец текущей строки ввода |
| Ctrl + ↑ / ↓ | Начало / конец всего многострочного ввода |
| Alt (Option) + ← / → | Перемещение назад / вперёд по словам |
| Alt + Shift + ← / → | Расширение или сокращение выделения по словам в Zsh |
| Ctrl + Shift + ← / → | Выделение до начала / конца текущей строки в Zsh |
| Ctrl + Shift + ↑ / ↓ | Выделение до начала / конца всего ввода в Zsh |
| Shift + Return / Enter | Перенос строки в буфере Zsh без выполнения команды |
| Return / Enter | Обычная отправка ввода оболочке |

Сочетания Command со стрелками не перехватываются. Стандартные сочетания Терминала с Command и Command + Shift остаются доступны.

Выделение с клавиатуры и многострочный ввод работают в интерактивном Zsh в Terminal.app. После установки откройте новую вкладку. Эти возможности не распространяются на историю вывода, удалённые оболочки без интеграции и полноэкранные приложения.

Shift + Enter вставляет настоящий перенос строки без обратного слеша. Обычный Enter передаёт буфер оболочке для разбора или выполнения.

## Автоматическое копирование

- Выделенный мышью текст копируется после отпускания кнопки.
- Выделенный с клавиатуры текст в Zsh копируется, если автокопирование включено.
- Пробелы и переносы строк сохраняются.
- Пустое выделение не очищает буфер обмена.
- Возвращение в Терминал с существующим выделением не перезаписывает буфер обмена.
- Backspace/Delete удаляет выделенный фрагмент Zsh; обычное перемещение снимает выделение.

Выделение мышью проверяется каждые 150 мс, поэтому очень короткое выделение может быть пропущено. Выделенный текст и вводимые команды не записываются в журнал и не передаются по сети.

## Настройки и оформление

Откройте **Системные настройки → Extended Terminal** на Monterey. Здесь можно включить или выключить копирование, клавиатурные возможности и автозапуск; запустить или остановить службу; запросить Универсальный доступ или повторно применить тему.

Значок — тёмный терминал с ядовито-зелёной шестерёнкой. Значков в строке меню и Dock нет; в папку «Программы» приложение не устанавливается.

Профиль iTerm Dark включает Monaco 12, цвета выделения и курсора, обычного и жирного текста, фона и все 16 цветов ANSI. Перед применением темы создаётся резервная копия. Конфигурация Zsh также сохраняется перед добавлением блока с метками.

Пакет содержит универсальные сборки для Intel и Apple Silicon. Панель настроек проверена на macOS 12 Monterey; новые версии Системных настроек не проверены.

## Разрешения

Службе нужен Универсальный доступ для копирования выделения мышью и перехвата клавиш. Для применения профиля требуется разрешение управлять Терминалом в разделе «Автоматизация». Эти разрешения выдаёт пользователь; установщик не может выдать их сам.

Если служба не появилась в списке Универсального доступа, нажмите **+ → Command + Shift + G** и добавьте `/Library/Application Support/Extended Terminal/Extended Terminal.app`.
