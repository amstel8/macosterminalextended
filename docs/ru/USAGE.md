# Использование и решение проблем

[English](../USAGE.md) · **Русский** · [Главная](../../README.ru.md)

## Настройки

Откройте **Системные настройки → Extended Terminal** на Monterey.

Можно включить или выключить копирование мышью, сочетания клавиш и выделение, а также автозапуск при входе. Кнопки позволяют запросить Универсальный доступ, применить тему, запустить или остановить службу. Панель показывает состояние разрешений службы.

Значков в строке меню и Dock нет. Служба находится в Library/Application Support.

## Сочетания клавиш

| Сочетание | Действие |
| --- | --- |
| Ctrl + ← | Начало текущей строки ввода |
| Ctrl + → | Конец текущей строки ввода |
| Ctrl + ↑ / ↓ | Начало / конец всего многострочного ввода |
| Alt (Option) + ← / → | Перемещение назад / вперёд по словам |
| Alt + Shift + ← / → | Расширение или сокращение выделения по словам в Zsh |
| Ctrl + Shift + ← / → | Выделение до начала / конца текущей строки |
| Ctrl + Shift + ↑ / ↓ | Выделение до начала / конца всего ввода в Zsh |
| Shift + Return / Enter | Перенос строки без выполнения команды |

Command со стрелками и Command + Shift со стрелками передаются без изменений, сохраняя стандартные сочетания Терминала.

Для выделения нужна новая интерактивная вкладка Zsh после установки и установленный профиль Терминала. Оно работает в редактируемой командной строке, а не в истории вывода или полноэкранных программах. Zsh подсвечивает выделенный фрагмент и копирует его в системный буфер обмена, если автокопирование включено. Backspace или Delete удаляет фрагмент; обычное перемещение снимает выделение.

Переход к границам строки отправляет Control + A / E. Приложения вроде vim задают собственное поведение этих клавиш.

Для Shift + Enter нужны виджет Zsh и профиль из комплекта. Сочетание вставляет настоящий перенос строки; обычный Enter отправляет буфер оболочке. После обновления откройте новую вкладку Zsh, чтобы загрузить виджет.

## Копирование

Выделите текст мышью, отпустите кнопку и вставьте его через Command + V. Пробелы и переносы строк сохраняются. Пустое выделение и возвращение к уже выделенному тексту не перезаписывают буфер обмена.

Служба проверяет выделение каждые 150 мс. Очень короткое выделение может быть пропущено. Чтобы повторно скопировать тот же текст, сначала снимите выделение.

## Быстрая проверка

1. Активируйте Терминал и подождите полсекунды.
2. Выделите текст мышью, отпустите кнопку и вставьте его в TextEdit.
3. Откройте новую вкладку Zsh, введите команду без Return и попробуйте Ctrl со стрелками.
4. Попробуйте Alt + Shift и Ctrl + Shift со стрелками, затем вставьте выделение в TextEdit.
5. Убедитесь, что Command + Shift со стрелками сохраняет стандартное поведение Терминала.

## Решение проблем

- **Копирование перестало работать после обновления:** удалите старую запись Универсального доступа и через Grant Accessibility заново добавьте `/Library/Application Support/Extended Terminal/Extended Terminal.app`.
- **Вместо выделения или переноса строки появляются символы:** откройте новую вкладку Zsh и примените профиль из комплекта. Интеграция не устанавливается на SSH-серверы и в другие оболочки.
- **tmux/vim перехватывает выделение мышью:** удерживайте Option для стандартного выделения Терминала.
- **Ctrl со стрелками переключает рабочие столы:** проверьте сочетания Mission Control, если macOS перехватывает клавиши.
- **Тема не применилась:** разрешите управление Терминалом в разделе «Автоматизация» и нажмите Apply Terminal theme.
- **Остался старый значок TC:** завершите ранний прототип Terminal Copy on Select через его меню.

## Диагностика

```sh
"/Library/Application Support/Extended Terminal/Extended Terminal.app/Contents/MacOS/TerminalCopyOnSelect" --probe
```

Команда сообщает о поддержке Универсального доступа, не печатая выделенный текст. При прямом запуске из оболочки может использоваться разрешение запускающего Терминала вместо разрешения самой службы.

Выделенный текст не записывается в журнал и не передаётся по сети.
