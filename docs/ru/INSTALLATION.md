# Установка и обновление

[English](../INSTALLATION.md) · **Русский** · [Главная](../../README.ru.md)

## Требования

- macOS 12 Monterey, Intel или Apple Silicon.
- Стандартный Terminal.app; интерактивный Zsh для выделения с клавиатуры.
- Права администратора для установки службы и панели настроек.

## Установка

1. Скачайте `macosterminalextended-0.3.2.pkg` из [релизов](https://github.com/amstel8/macosterminalextended/releases/latest) и завершите установку.
2. Откройте **Системные настройки → Extended Terminal**.
3. Нажмите **Grant Accessibility**, чтобы показать скрытую службу и открыть настройки разрешений.
4. Разблокируйте **Защита и безопасность → Конфиденциальность → Универсальный доступ**. Добавьте показанное приложение **Extended Terminal.app** и включите его флажок. Если приложения нет в списке, нажмите **+**, затем **Command + Shift + G**, вставьте `/Library/Application Support/Extended Terminal/Extended Terminal.app`, нажмите «Открыть» и включите флажок приложения с зелёной шестерёнкой. Сам запрос macOS не гарантирует, что приложение автоматически появится в списке.
5. Разрешите Extended Terminal управлять Терминалом в разделе **«Автоматизация»** для применения темы.
6. Откройте новую вкладку Zsh, чтобы загрузить выделение с клавиатуры.

Разрешения нужно выдать вручную. У пакета нет подписи Developer ID и нотариализации Apple. Панель настроек проверена на Monterey; более новые версии Системных настроек не проверены.

## Устанавливаемые файлы

- Служба: `/Library/Application Support/Extended Terminal/Extended Terminal.app`.
- Настройки: `/Library/PreferencePanes/Extended Terminal.prefPane`.
- Автозапуск: `~/Library/LaunchAgents/dev.local.ExtendedTerminal.plist`.
- Интеграция оболочки: блок с метками **BEGIN/END Extended Terminal** в `~/.zshrc`.
- Резервная копия конфигурации: `~/.zshrc.extended-terminal-backup-TIMESTAMP`.
- Резервные копии темы: `~/Library/Application Support/Extended Terminal/Backups/`.

В папку «Программы» приложение не устанавливается. Служба остаётся пакетом приложения, потому что macOS использует его для идентификации разрешения Универсального доступа.

Профиль iTerm Dark сохраняет Monaco 12 и исходные цвета. Он также настраивает последовательности клавиш для навигации, выделения и многострочного ввода. Тема применяется к открытым вкладкам и становится стандартной для новых окон и окон при запуске. Шрифт Monaco уже входит в macOS.

Установщик настраивает автозапуск и оболочку для вошедшего в систему пользователя. Другие пользователи могут включить автозапуск через панель настроек, но блок подключения Zsh нужно добавить в их собственную конфигурацию.

Если вы используете свой `ZDOTDIR`, подключите `Contents/Resources/extended-terminal.zsh` из пакета службы в активной конфигурации Zsh вместо стандартного `~/.zshrc`.

## Обновление с 0.2

Установщик переносит службу из папки «Программы» и удаляет только старое приложение с совпадающим идентификатором пакета. Настройки сохраняются, автозапуск обновляется.

Если после обновления доступ перестал работать, заново добавьте скрытую службу в Универсальный доступ: у локально подписанной сборки может измениться идентичность кода.

## Удаление

Отключите автозапуск и остановите службу в панели настроек. С правами администратора удалите службу и панель настроек. Удалите блок Extended Terminal из конфигурации Zsh и откройте новую оболочку.

Профиль Терминала и резервные копии остаются. Для восстановления оформления выберите предыдущий профиль в настройках Терминала.
