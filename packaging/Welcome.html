Extended Terminal

Дополнение для стандартного Terminal.app на macOS 12 и новее.

  • Автоматическое копирование выделенного текста.
  • Ctrl + ← / → — переключение вкладок.
  • ⌘ + ← / → — начало и конец строки в оболочке.
  • Профиль iTerm Dark: Monaco 12, все цвета, выделение и курсор.

Приложение работает в фоне без значка в строке меню. Установщик добавит запуск при входе для текущего пользователя.

После установки разрешите «Универсальный доступ» для Extended Terminal, а для применения оформления — управление Terminal в разделе «Автоматизация». Окно настроек открывается запуском Extended Terminal из папки «Программы».

Перед применением темы сохраняется резервная копия настроек оформления.
