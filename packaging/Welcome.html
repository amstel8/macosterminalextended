Extended Terminal

Дополнение для стандартного Terminal.app на macOS 12 и новее.

  • Автоматическое копирование выделенного текста.
  • Ctrl + ← / → — начало и конец строки.
  • Alt + Shift + ← / → — выделение по словам в zsh.
  • Ctrl + Shift + ← / → — выделение до начала и конца строки в zsh.
  • Профиль iTerm Dark: Monaco 12, все цвета, выделение и курсор.

Приложение работает в фоне без значка в строке меню. Установщик добавит запуск при входе для текущего пользователя.

После установки разрешите «Универсальный доступ» для Extended Terminal, а для применения оформления — управление Terminal в разделе «Автоматизация». Настройки находятся в панели Extended Terminal в системных настройках Monterey. Сервис хранится в Library/Application Support. Для новых сочетаний откройте новую вкладку zsh.

Перед применением темы сохраняется резервная копия настроек оформления.
